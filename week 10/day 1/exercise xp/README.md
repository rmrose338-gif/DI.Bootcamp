# Week 10, Day 1: React + TypeScript

A Vite project for practicing typed React components, props, state, and effects.

## Run the project

```sh
npm install
npm run dev
```

Run the TypeScript check and production build with:

```sh
npm run build
```

## Exercises

1. **Greeting props** — `src/components/Greeting.tsx` types a name and message count.
2. **Counter state** — `src/components/Counter.tsx` uses typed state for the value and last action.
3. **Optional props** — `src/components/UserCard.tsx` provides defaults for name, age, and role.
4. **Fetch with an effect** — `src/components/UserList.tsx` fetches typed user data and displays loading and error states.

`src/App.tsx` renders each exercise with example props and interaction.
